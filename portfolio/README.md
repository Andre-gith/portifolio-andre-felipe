# André Felipe — Portfolio

Portfólio pessoal implementado com React + Vite + Tailwind CSS. Esta versão foi reestruturada para apresentar projetos selecionados e integração com o GitHub.

## Preview

Nenhuma screenshot real válida está disponível no workspace. Coloque as imagens reais em `public/screenshots/` com os nomes:

- `desktop.png`
- `tablet.png`
- `mobile.png`

Após inserir as imagens, a seção de pré-visualização será exibida automaticamente.

## Run locally

```bash
cd portfolio
npm install
npm run dev
```

## Build

```bash
cd portfolio
npm run build
```

## Configuration

- Edite `src/config.js` para definir `CONTACT_EMAIL` e `featuredRepositories` (nomes exatos dos repositórios GitHub que serão destacados).
